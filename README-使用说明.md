# 公众号采集 → 整理 → 选题 → 写作 → 发布 全流程使用说明

本工具包实现一条完整的公众号内容流水线：**爬取文章 → 汇总整理 → 选题 → 写作成稿（AI配图）→ 发布到公众号草稿箱**。

## 一、工具包结构

```
公众号采集流水线-分享包/
├── SKILL.md                      # 流程规则总纲（整理→选题→写作→发布）
├── publish_wechat.py             # 发布脚本（成稿 → 公众号草稿箱）
├── resolve_images.py             # 配图脚本（按占位符名字自动匹配图片）
├── .env.example                  # 凭证模板 → 复制为 .env 后填写
├── 公众号采集工具/
│   ├── collect_articles.py       # 爬取脚本（纯Python，无需第三方库）
│   └── README.md                 # 爬取脚本详细说明
├── references/                   # 三环节模板
│   ├── summary-template.md       #   每日汇总模板
│   ├── ideas-template.md         #   选题池模板
│   └── writing-guide.md          #   写作规范（含配图规则）
├── 00-Inbox 原始/                # 爬取结果存放（自动生成，按日期分文件夹）
├── 05-Summary 整理/              # 每日汇总产出
├── 10-Ideas 选题/                # 选题池产出
└── 15-Published 发布/            # 成稿+配图产出（按日期分文件夹）
```

## 二、初始化（拿到后只需做一次）

### 1. 放入你的 Obsidian 库

把整个 `公众号采集流水线-分享包` 文件夹拷入你的 Obsidian 库（可改名，如 `01_爬取专用`）。

### 2. 配置爬取脚本路径

用文本编辑器打开 `公众号采集工具/collect_articles.py`，改顶部 `OUTPUT_DIR` 为你的实际路径：

```python
OUTPUT_DIR = "/Users/你的名字/Obsidian库路径/公众号采集流水线-分享包/00-Inbox 原始"
```

> Windows 示例：`"C:/Users/你的名字/Documents/Obsidian/公众号采集流水线-分享包/00-Inbox 原始"`（用正斜杠）

### 3. 配置公众号凭证

```bash
cd 公众号采集流水线-分享包
cp .env.example .env
```

编辑 `.env`，填入你的公众号凭证：
- `WECHAT_APPID`：公众号后台 → 设置与开发 → 基本配置 → 开发者ID
- `WECHAT_APPSECRET`：同页"开发者密码"处重置生成（只显示一次，立即复制）
- **IP白名单**：同页把 IP 白名单配置为你的公网 IP（终端运行 `curl ifconfig.me` 查询），保存需管理员扫码

### 4.（可选）增删采集公众号

编辑 `公众号采集工具/collect_articles.py` 顶部 `ACCOUNTS` 列表，按注释格式增删即可。

## 三、日常使用（每天 3 步）

### 第1步：爬取（自己做）

```bash
cd 公众号采集流水线-分享包/公众号采集工具
python3 collect_articles.py
```

结果存到 `00-Inbox 原始/公众号采集-当天日期/`。

### 第2步：整理+选题（告诉 AI 执行）

对 AI 说：
> "执行 skill，根据 {日期} 的采集，帮我整理汇总"

流程：
- 先出**文章速览表**（只列标题，省 token）→ 你勾选要整理的篇目（说"整理全部"则全量）
- 生成 `05-Summary 整理/每日汇总-{日期}.md`

再说：
> "帮我出选题"

生成 `10-Ideas 选题/选题池-{日期}.md`（支持多选 / 换一批 / 指定话题）。

### 第3步：写作 + 配图 + 发布（告诉 AI 执行）

> "根据 {日期} 的采集，输出 N 篇文章，发布到我的公众号草稿"

- AI 写稿时图片位置用占位符 `![图N-建议内容]()`，并给你图位清单
- 配图二选一：
  - **手动**：你按占位符名字命名图片放入 `15-Published 发布/{日期}/images-{标题}/`，AI 跑 `resolve_images.py` 自动匹配
  - **AI 生图**：让 AI 生成原创配图
- 全部配齐后 AI 发布到公众号草稿箱，你到后台确认后再正式群发

## 四、环境要求

- Python 3.6+（macOS 自带；Windows 需安装并勾选 Add to PATH）
- 无需安装任何第三方库
- 发布功能需公众号（订阅号即可，个人可注册）并完成上述凭证配置

## 五、常见问题

| 问题 | 解决 |
|---|---|
| 爬取报 SSL 证书错误 | 脚本已内置容错，自动降级不验证证书，不影响使用 |
| access_token 报 invalid ip | 你的公网 IP 变了，去公众号后台更新 IP 白名单 |
| 发布时提示缺图 | 成稿还有占位符未配图，按缺图清单补图后重跑 |
| 想加其他公众号 | 有网易号的加一行到 ACCOUNTS；其他平台需另写采集逻辑（见采集工具 README） |
