# 每日汇总模板

生成位置：`05-Summary 整理/每日汇总-YYYY-MM-DD.md`

## 模板

```markdown
# 每日资讯汇总 - YYYY-MM-DD

> 采集自 APPSO、硅星人、极客公园、新智元 等公众号，共 X 篇
> 本次已深度整理 N 篇（用户勾选），未整理 M 篇（仅列标题，见文末）

## 🔥 AI 大模型
- **《标题》**（公众号名 · 发布时间）：核心要点1；核心要点2。
- **《标题》**（公众号名 · 发布时间）：核心要点1；核心要点2。

## 📱 硬件 / 数码
- **《标题》**（公众号名 · 发布时间）：核心要点1；核心要点2。

## 💼 行业 / 商业动态
- **《标题》**（公众号名 · 发布时间）：核心要点1；核心要点2。

## 💰 融资 / 创业
- **《标题》**（公众号名 · 发布时间）：核心要点1；核心要点2。

## 📊 数据速览
| 分类 | 篇数 |
|------|------|
| AI 大模型 | X |
| 硬件 / 数码 | X |
| 行业 / 商业 | X |
| 融资 / 创业 | X |

## 📋 未整理列表（仅标题，便于回溯）
- 《标题》（公众号名 · 时间）
- 《标题》（公众号名 · 时间）
```

## 要求

- 每篇要点控制在 2-3 句，突出"发生了什么 + 为什么重要"
- 新智元为短资讯（几百字），可多条合并为一条要点
- 分类不匹配时归入"其他"，或调整分类标签
- 保留原文链接（如有），便于回溯
- **勾选模式**：用户勾选后只深度整理选中的；"整理全部"则全量。汇总开头注明已整理/未整理篇数
- **速览表**：整理前先给用户编号标题清单（只读标题+一句话），等用户勾选后再读正文深度整理
