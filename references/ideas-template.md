# 选题池模板

生成位置：`10-Ideas 选题/选题池-YYYY-MM-DD.md`

## 模板

```markdown
# 选题池 - YYYY-MM-DD

> 基于当日资讯汇总，提炼候选选题。人工从中挑选 1-3 个执行。

## 选题 1：《标题》
- **核心观点**：一句话说明这篇文章要表达什么
- **切入角度**：从哪个视角切入（体验实测 / 行业解读 / 对比分析 / 趋势预判）
- **参考素材**：
  - 《素材文章1》（公众号名）
  - 《素材文章2》（公众号名）
- **预估字数**：2000 字 | **难度**：中
- **竞争力**：为什么这个选题值得写（时效性 / 稀缺性 / 读者关注度）

## 选题 2：《标题》
- ...

## 选题 3：《标题》
- ...

## 选题 4：《标题》
- ...

## 选题 5：《标题》
- ...
```

## 要求

- 每次生成 3-5 个选题，覆盖不同角度（至少有 1 个时效性强的热点选题）
- 标题要吸引人，但不得标题党（与内容相符）
- 每个选题必须明确引用至少 1 篇采集素材，确保有料可写
- 避免与素材原文"复述"式重复，要有增量观点
